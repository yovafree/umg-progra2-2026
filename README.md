# UMG Programación II - Ejemplos de clase

Este repositorio contiene los ejemplos y prácticas desarrollados para el curso de Programación II en la Universidad Mariano Gálvez (UMG). Su objetivo es organizar los ejercicios por clase para facilitar su consulta y seguimiento.

## Estructura del repositorio

- [Clase4](Clase4/)
  - Contiene los ejemplos correspondientes a la cuarta clase del curso.
  - La documentación detallada de esta clase se encuentra en [Clase4/README.md](Clase4/README.md).

## ¿Qué incluye este repositorio?

- Ejemplos de programación en Java.
- Prácticas organizadas por clases.
- Material de apoyo para estudiar y repasar conceptos básicos de programación.

## Requisitos previos

Para ejecutar los ejemplos, se recomienda tener instalado:

- Java 17 o superior
- Maven
- Un IDE como NetBeans, IntelliJ IDEA o VS Code

## Cómo usar este repositorio

1. Ingrese a la carpeta de la clase que desea revisar.
2. Abra el README correspondiente para ver la explicación del contenido.
3. Ejecute los ejemplos siguiendo las instrucciones específicas de cada proyecto.

## Nota

Este repositorio irá creciendo conforme se incorporen los ejemplos de las siguientes clases del curso.
