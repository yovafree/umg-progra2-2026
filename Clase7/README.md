# Clase 7 - Tipos de accesos y listas de objetos

Este modulo contiene un ejemplo practico en Java sobre:

- Accesos a clases, metodos y atributos: public, private, protected.
- Listas de objetos basadas en clases personalizadas (`List`).
- Operaciones basicas sobre listas: agregar, modificar, eliminar, buscar.
- Uso de listas de objetos para almacenar informacion de formularios en memoria.

## Estructura

- `EjemploAccesosListas/`: proyecto Maven con el ejemplo ejecutable.

## Ejecutar

Desde `Clase7/EjemploAccesosListas`:

```bash
mvn compile exec:java
```
