# Clase 4 - Programación II

Esta carpeta contiene los ejemplos desarrollados para la Clase 4 del curso de Programación II.

## Contenido

- [Ejemplo1](Ejemplo1/)
  - Proyecto básico en Java que muestra conceptos fundamentales de programación.

## Temas abordados

En este ejemplo se practican:

- Variables y tipos de datos
- Operaciones aritméticas
- Estructuras de control
  - if/else
  - switch
  - for
  - while
  - do/while

## Ejecutar el ejemplo

Diríjase a la carpeta del proyecto y ejecute:

```bash
cd Ejemplo1
mvn clean compile
mvn exec:java -Dexec.mainClass=edu.umg.ejemplo1.Ejemplo1
```

## Observación

La documentación de cada clase se irá agregando en su respectiva carpeta para mantener el repositorio organizado.
